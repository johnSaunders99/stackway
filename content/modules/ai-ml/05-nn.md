## 為什麼要學：模型不是一個神祕的檔案
你收到一批形狀為「樣本數乘以 2」的工作資料，想讓模型對每筆工作給出 2 個分數：準時或逾時。神經網路（neural network）可以先看成把幾個有參數的運算串在一起。這堂的驗收不看它猜得準不準，而是你能不能指出有哪些可學習的參數，以及每一筆資料如何走到最後的 2 個分數。

## 核心概念：登記零件，再定義路線
PyTorch 的 `nn.Module` 是模型及子層的基底類別。在建構時先呼叫父類別的初始化，再把層指定給物件屬性，框架才會把它們登記為子模組（submodule）。如此一來，之後列出參數、儲存權重或移動裝置時，可以沿著登記的結構找到它們。不要在每次接收輸入時臨時建立一套新層，否則前一次學到的參數就無法穩定沿用。

線性層（linear layer）將每筆輸入的特徵乘以權重、加上偏差，最後一軸從指定的輸入欄數變成輸出欄數。這次先從 2 欄轉成 3 欄中間表示，再從 3 欄轉成 2 個類別分數。中間放一個整流線性單元（ReLU）：負數變 0，非負數保留。沒有中間的非線性，單純串接兩次線性加偏差，整體仍能寫成一次線性加偏差。

## 範例：沿著前向路線畫形狀
把下列程式存成 `ml-notes` 中的 `network.py`。在該資料夾，PowerShell 執行 `.\.venv\Scripts\python.exe network.py`；bash 用 `.venv/bin/python network.py`。先以筆畫出 4 列各有幾欄，再看列印結果。
```python
import torch
from torch import nn

class QueueNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.hidden = nn.Linear(2, 3)
        self.head = nn.Linear(3, 2)

    def forward(self, x):
        h = torch.relu(self.hidden(x))
        return self.head(h)

net = QueueNet()
x = torch.ones(4, 2)
print(tuple(x.shape), tuple(net.hidden(x).shape), tuple(net(x).shape))
for name, p in net.named_parameters():
    print(name, tuple(p.shape))
```
前向運算（forward pass）描述這次怎麼從輸入得到輸出。`net(x)` 會透過模組的呼叫介面執行 `forward`；不要為了省事而一律直接呼叫 `net.forward(x)`。列出的參數有 2 組權重與 2 組偏差，第一層的權重是 3 列 2 欄，表示每個輸出特徵各有 2 個輸入權重。這是框架儲存權重的方向，不代表輸入批次該倒過來排列。

### 找出第 1 個不相容的位置
假設把第一層改成輸出 5 欄，第二層仍設定接收 3 欄，光看最終要求輸出 2 欄找不到原因。從輸入往前走，在兩個子層中間標記實際欄數，再問下一層期待幾欄，就能精確指出第一次不一致的位置。這比隨機交換維度安全，也不會為了讓程式能跑而破壞樣本軸的意義。

## 常見錯誤
看到最後有 2 個數字，就認為它們已是相加等於 1 的機率。這裡輸出的是未正規化分數（logits），甚至可能為負；它們不直接表示百分比。另一個錯誤是為了增加批量，把線性層輸入大小從 2 改成 4。批次只改列數，層需要的特徵欄數沒變。檢查時分開讀「多少筆」與「每筆多少欄」。

先用小批資料檢查輸出的形狀，再問模型是否學到東西；形狀正確是能繼續訓練的條件，不是準確率證明。

## 小結
把模型看成可列舉的零件和一條具體的資料路線。若能從輸入走到 2 個分數，也能從參數清單找到對應的層，就有足夠基礎去討論這些數字下一步如何被學習。
