## 為什麼要學
同一張紙條，可以在不同的桌子上讀。同一份文字檔，也不屬於某一個編輯器（editor）。剛開始學程式，常見的困擾不是打錯字，而是你明明改了字，另一個畫面卻沒有變。今天用已經找得到的筆記做一個對照：只改一行，關掉編輯工具，請另一個視窗幫你驗收。你會知道改到的是原檔，還是另一份長得很像的副本。

## 核心概念
編輯器是改內容的工具；分頁（tab）則是工具裡顯示一份文件的位置。開啟資料夾，是讓工具看見一組檔案；開啟檔案，是挑出其中一份來讀寫。這兩個動作都不等於「複製一份」。除非執行儲存，畫面上新打的字可能還沒寫進磁碟。反過來說，關掉分頁通常也沒有移除磁碟上的檔案。

Visual Studio Code（簡稱 VS Code）是一種程式碼編輯器。如果這台電腦已經有它，從開始功能表開啟，選「檔案 → 開啟資料夾」，選 `C:\dev\stackway-lab\desk`。只開自己建立的那個。左邊應該會列出筆記，點檔名即可。若沒有安裝權限，不用為了這堂調整電腦：改用記事本的「檔案 → 開啟」選同一份筆記，仍能完成下面最重要的實驗。想沿用 VS Code 且這台電腦允許安裝時，到延伸資源的 Windows 官方說明選 User Setup，依畫面安裝，再從開始功能表開啟；後面各堂直接用已經能儲存這份筆記的編輯器。

## 範例：替下一位讀者補一條驗收線索
回到檔案總管，在這個資料夾找到上一堂留下的 `desk-note.txt`。若先前另取檔名，就使用那個檔名。若你在記事本練習，也可以先按 Windows 鍵＋R，執行下面一行，再用 Ctrl＋O 選取那份檔案。兩種做法都從既有檔案出發，不是新開一張空白紙。

```text
notepad.exe
```

先讀原來的第二行，確認沒有開錯。把游標移到最後，另起一行寫「驗收：能從資料夾重新打開這三行。」按 Ctrl＋S。這次你開的是原有檔案，所以通常不會再被問檔名與位置。接著關閉這個文件分頁，從檔案總管開啟同一份檔案。若有兩種編輯器，可用右鍵「開啟方式」選另一種；若只有記事本，完全關閉該文件後再開也可以。核對第一行仍在、第三行只出現一次，並確認資料夾沒有多出一份新筆記。

## 常見錯誤
看到空白畫面，不要急著重新輸入三行。有可能只是進了歡迎頁或新增分頁；先確認分頁標題是不是原來的檔名。如果切換工具時兩邊內容不一樣，先確認正在編輯的分頁已把修改存回指定路徑，再關閉另一邊沒改過的舊分頁，從同一路徑重開。不要讓兩個工具同時儲存彼此不知道的變更。想比較兩個版本時，先取不同的名字，比猜哪個視窗最後存檔可靠。

## 小結
能從資料夾重新驗收第三行，也能解釋為什麼資料夾並沒有多一份檔案，就夠了。往後看到「開啟專案」，先想到的是打開一個工作資料夾，而不是把東西上傳，或替每份檔案選定唯一的工具。
